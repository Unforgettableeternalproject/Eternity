# 構想 · Roadmap

> 最後更新：2026-06-09 · 目前版本：v0.9.8（hotfix/v0.9.8 分支）

## 專案總覽

Eternity 是一個個人網站 monorepo，包含主站（apps/root）與 UEP 文件站（apps/uep），
以 pnpm workspaces + Turborepo 管理，部署在 Cloudflare Pages + Workers（D1 + R2 + KV）。

---

## 目前狀態

### ✅ 主站（apps/root）— 幾乎完成

核心功能皆已完成：

- **頁面系統**：首頁、關於、作品、動態、連結、聯絡，全部 SSR + D1 API
- **i18n**：繁中 / 英文雙語，pathname 策略
- **Admin 編輯器**：TipTap 三欄編輯器（entry list ∣ 編輯區 ∣ Inspector）
- **媒體管理**：獨立 R2 bucket（`eternity-root-assets`），含媒體庫 + ImagePicker
- **Widget 系統**：toolbox/edge-tabs 雙模式，6 個 widget 卡片
- **搜尋**：全站搜尋（GlobalSearch）
- **聯絡表單**：TipTap 富文本 + Resend API
- **互動元素**：可拖曳卡片、圖片檢視器、打字機音效、U.E.P 角色、每日名言
- **Keystatic 完全移除**，所有資料走 D1 API

### ✅ 文件站（apps/uep）— Epic 1 完成，Epic 2 待做

Epic 1（正式機前）核心全部完成：

- **六大 Zone**：history、echoes、visuals、concepts、storage、portal
- **專屬 Reader**：每個 zone 有獨立的前台閱讀器，各有專屬的 boot 動畫、背景特效、頁面轉場
- **共用 Reader 基礎設施**：ReaderShell、ZoneStateDisplay、ZonePrevNext、ZoneBreadcrumb、useZoneRouter、useScrollMemory、useZoneBootReady、contentVisibility
- **首頁空間系統**：Hero → Atlas → 五個 Zone Journey → Eternal Verse，空間轉場而非長頁捲動
- **Admin 後台**：TipTap 富文字編輯器 + 各 zone 專屬編輯模式、EditorPageTree（拖曳排序 + inline create + context menu）
- **設計系統**：DesignLayout、TopBar、Minimap、BigMapModal、IntroOverlay、PortalTransition、ZoneAtmosphere
- **D1 + R2 資料層**：content-api Worker 處理所有 CRUD、資產管理、內容同步

### ✅ Workers — 穩定運行

- **content-api**（port 8788）：D1 資料庫 + R2 資產儲存，負責兩站的所有 CRUD 和同步
- **visitor-counter**（port 8787）：KV 訪客計數

### ✅ 基礎設施

- **CI/CD**：GitHub Actions，PR 時自動 lint + typecheck + format + build
- **測試**：Vitest 前端單元 + Worker 整合 + Playwright E2E + 壓力測試
- **分支策略**：main（production）← develop（日常開發）、staging（測試部署）
- **同步系統**：`pnpm sync` 雙向 D1 同步（本地 ↔ 遠端）

## 下一次部署目標

> **Release gate：文件站 Epic 2 完成後**

文件站 Epic 2 是正式機後的下一個大型功能迭代，核心是 **History-centered zone islands**——
讓五個 zone 之間產生跨區互動，而非各自獨立運作。

### Epic 2 分期規劃

#### Phase 0：History Interactive Embed（基礎，最重要）

> 所有後續 island 的第一依賴

- TipTap 新增 `UepEntityMark` / `UepInteractiveMark`：inline 標記角色、地點、術語、歌曲、圖片 cue
- History Editor toolbar 新增 reference picker（跨 zone 搜尋 Concepts/Echoes/Visuals 資源）
- HistoryReader 前台 renderer + click dispatcher（dispatch `uep:entity-activate`、`uep:media-cue` 等事件）
- 頁面 `metadata.related` / `metadata.cues` summary，讓 islands 不必解析整篇 HTML

```html
<!-- 目標 HTML 結構 -->
<span data-uep-entity="character" data-ref="concepts/log/characters/asvere">艾斯維爾</span>
<span data-uep-cue="song" data-ref="echoes/...">...</span>
```

#### Phase 1：History Context Broadcast + Island Runtime

- HistoryReader 廣播 `HistoryContext`（currentPage、ancestors、progress、related/cues）
- `DraggableIsland` / `IslandDock` / `useIslandPersistence`：可拖曳、可收合、位置保存、z-index/focus 管理
- History Island：顯示最近閱讀、目前章節、基本進度
- localStorage key 加版本：`uep.islands.v1.{id}`
- 桌面浮動，手機改 bottom sheet / dock button

#### Phase 2：Concepts Terminal Island

- 從 Eternity-Design `TerminalIsland` 原型移植互動骨架
- 點擊 History 中的人物/地點/術語 → 開啟 mini dossier（名稱、類型、摘要、開啟完整頁面）
- ref 格式支援 page-level 與 structured-entry-level

#### Phase 3：Visuals Portable Viewer

- 手動釘選/展示圖片，可帶到其他區域
- 接 History `related.images` cue
- 自動展示預設關閉（避免劇透）

#### Phase 4：Storage Scratchpad

- 從 Eternity-Design `Scratchpad` 原型移植
- localStorage 便條紙，可拖曳/收合/刪改
- 與 History-centered 互動關係較弱，可平行進行
- 儲存格式預留 `version`、`createdAt`、`updatedAt`

#### Phase 5：Echoes Cross-zone Playlist

- 手動加入播放清單 + 跨區播放（最難的 island，音訊生命週期 + autoplay 限制）
- 再做 History page 推薦曲目
- 自動播放必須 opt-in

#### Phase 6：History Chapter Gating

- soft gate + 防劇透 warning
- `progress.completedPageIds` + `metadata.spoilerGate`
- admin metadata UI
- hard lock 視內容策略再決定

### Epic 2 難度總表

| 項目 | 難度 | 主要風險 | 建議順序 |
|------|------|----------|----------|
| History interactive embed | 高 | TipTap extension、renderer、metadata summary 需一致 | 0 |
| Island runtime | 中 | 跨 React island singleton、拖曳/手機版/持久化 | 1 |
| History island | 中 | 閱讀進度/gating 若一次做太大會失控 | 2 |
| Concepts terminal | 中 | reference picker 與 structured entry 對應 | 3 |
| Visuals viewer | 中 | 圖片 metadata 差異、自動展示劇透風險 | 4 |
| Storage scratchpad | 低-中 | localStorage 與未來帳號同步遷移 | 可平行 |
| Echoes playlist | 高 | 音訊生命週期、跨頁不中斷、autoplay 限制 | 6 |
| History gating | 高 | 內容解鎖規則、回訪體驗、管理 UI | 7 |
