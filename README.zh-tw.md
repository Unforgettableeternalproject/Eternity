## 專案概述

Eternity 是 Bernie 的個人網站專案，整合了個人介紹、創作展示與知識庫等多個功能模組。本專案目前處於開發初期階段，架構規劃中。

## 主要功能

🌟 **個人網頁**

- 個人簡介與聯絡方式
- 專案作品集展示
- 技術棧與技能展示

📚 **Gitbook 知識庫**

- 個人創作文章
- 技術筆記與教學
- 專案文件整理
